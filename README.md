FloraVision — Earth's Exhale 🌿
FloraVision is a plant-themed website that showcases indoor plants and greenery through a nature-inspired, modern interface. It features a dark forest-green visual theme, plant photography, product cards, customer reviews, and an informational section about oxygen-producing plants.
✨ Features
- Responsive layout with desktop and mobile styling.
- Hero section introducing FloraVision and its nature-inspired theme.
- Plant highlights featuring selected plants.
- Plant product gallery with images, descriptions, and displayed prices.
- Customer reviews section with reviewer profiles and ratings.
- Our Best O2 informational section about plants and air quality.
- Newsletter subscription area in the footer.
- Visual interactions including hover effects, glass-style cards, and smooth scrolling.
🛠️ Built With
- HTML5
- CSS3
- Google Fonts — Poppins
- SVG icons
- Local image assets (PNG and JPG)

🚀 Getting Started
No package installation or build step is required.
1. Download or clone this repository.
2. Open the project folder.
3. Make sure index.html, style.css, and all image assets remain together.
4. Open index.html in a web browser.
Run with VS Code (optional)
1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension if it is not already installed.
3. Right-click index.html.
4. Select Open with Live Server.

⚠️ Current Scope
This project is a front-end website built with HTML and CSS. The provided project files do not include a backend, database, authentication, or payment integration.

The search, cart, purchase, navigation, and newsletter elements are part of the interface; their full functionality would require additional JavaScript and/or backend integration.
